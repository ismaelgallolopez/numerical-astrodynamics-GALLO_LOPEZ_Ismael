\section*{AI Usage Summary}

\subsection*{Description of Usage}

For this assignment, AI tools were used exclusively for debugging assistance, conceptual clarification, and implementation guidance related to TudatPy simulations.

Specifically, AI was consulted to:

\begin{itemize}
  \item Interpret and resolve runtime errors related to radiation pressure interface configuration and order-of-operations issues in environment setup.
  \item Understand how to correctly retrieve individual accelerations using the AvailableAcceleration enumeration and dependent variable system.
  \item Clarify frame consistency issues (e.g., body-fixed vs inertial frames) when comparing analytical and numerical accelerations.
  \item Debug indexing issues when extracting data from dependent variable dictionaries and converting them into NumPy arrays.
  \item Conceptually reason about the physical and mathematical implications of changing the propagation origin (e.g., Ganymede-centered vs. Jupiter-centered propagation).
  \item Verify whether the implemented numerical comparison strategy for Question 4 logically addressed the assignment requirements.
  \item Write this very document, summarizing the AI interactions and their role in the assignment.
\end{itemize}

AI was not used to generate derivations, formulate analytical models, write propagation algorithms, produce executable assignment solutions, compute numerical results, or generate report-ready explanations for the assignment questions. All mathematical formulations, implementation decisions, simulations, and analysis were developed independently.

The AI interactions served as debugging support and conceptual discussion, comparable to consulting peers regarding implementation issues.

The mathematical formulation, implementation of the dynamical model, propagation runs, and analysis of the results were carried out independently.
